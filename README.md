Este repositorio reúne el trabajo y las prácticas realizadas durante el módulo de **Programación** del ciclo formativo de **Desarrollo de Aplicaciones Web (1º DAW)**. 

Contiene más de 100 ejercicios estructurados que muestran la evolución y el aprendizaje progresivo del lenguaje Java a lo largo de 198 commits.

---

## 📌 Contenido General

Los proyectos y ejercicios abarcan los principales pilares del desarrollo en Java:

*   **Fundamentos de Programación:** Sintaxis, condicionales, bucles, funciones y arrays.
*   **Programación Orientada a Objetos (POO):** Clases, objetos, herencia, polimorfismo e interfaces.
*   **Gestión de Datos:** Colecciones, manejo de excepciones y persistencia en ficheros.
*   **Interfaces de Usuario:** Aplicaciones interactivas y formularios visuales (GUI).

---

## 🛠️ Tecnologías

* **Lenguaje:** Java
* **Herramientas:** IDEs: NetBeans y Git
